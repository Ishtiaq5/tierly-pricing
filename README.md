# Tierly — Pricing that scales with you

A premium dark-themed pricing page built with vanilla HTML, CSS, and JavaScript.
No frameworks, no CDNs, no build step.

## Features

- Monthly / yearly billing toggle with animated price swap and ARIA switch semantics
- Glassmorphism plan cards with a gradient-bordered "Most popular" tier
- Bold gradient headline, glow accents, and subtle grid backdrop
- Price-lock guarantee strip with hover micro-interactions
- Fully responsive from 360px up; respects `prefers-reduced-motion`

## Run locally

Open `index.html` in any modern browser — that is it.

## Stack

- Semantic HTML5
- Modern CSS (custom properties, grid, backdrop-filter, clamp)
- ~40 lines of vanilla JavaScript
